# ORBIS Hair Fan Meet — demo

Mobile-first, interactive prototype for trying the customer and admin journeys. This public repository contains only the static demo files. All names, receipts, OTPs, and campaign results are fictional.

Open the [live demo](https://manmercy.github.io/orbis-hair-fanmeet-demo/) on a phone or desktop. Use the sample receipt button to try the flow. The demo OTP appears on screen.

This is a browser-only prototype. Data is stored in each visitor's browser and is not shared between devices or visitors. It is not connected to LINE, email, a server, or a real promotion. Do not enter real personal information or upload real receipts.
